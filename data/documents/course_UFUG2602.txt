description: >
  This course introduces common data structures and algorithms. Data structures include arrays and matrices, linked lists, stacks, priority queues, hash tables, trees, and graphs. Algorithms include sorting, hashing, searching, greedy methods, divide-and-conquer, dynamic programming, and branch-and-bound. Students will learn Python implementations of these data structures and algorithms, and solve programming problems with learned techniques.
