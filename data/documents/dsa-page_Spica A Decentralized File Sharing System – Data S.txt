  Research Project
  Spica: A Decentralized File Sharing System
  Abstract
  Spica is a decentralized file-sharing system based on a distributed network. With Spica, user files can be stored securely and redundantly on different users' PC devices and mobile devices. At the same time, the traceability of files on Spica is ensured through blockchain technology.
